01Visual Tokens · 视觉 Token
背景 #FFFDF5，主色 #FFE600
辅助 #FF5C39 / #3D5AFE
边框 3px solid #000，全站统一
圆角：卡片与按钮 0，徽章 999px
阴影 6px 6px 0 #000，零模糊，全站唯一
字体 Inter，字号 14/16/20/32/56
02Layout · 布局骨架
单列，最大宽 1120px，左右留白 24px
顺序：导航 → Hero → 特性三宫格 →
步骤 → 价格 → 页脚
区块间距 80px，Hero 上下 96px
03Components · 组件规范
按钮：黑底白字 3px 黑边，hover 位移 (2,2)
卡片：白底 3px 黑边，实心黑影，hover 上移 4px
输入框：白底 3px 黑边，focus 加 2px 蓝描边
导航：底部 3px 黑线分隔
04Forbidden · 禁止事项
  • 不要任何模糊半径大于 0 的阴影
  • 不要使用渐变，三种全部禁止
  • 不要 4–8px 的暧昧圆角
  • 不要低饱和莫兰迪色
05Acceptance · 验收标准
  • 所有可见边框均为 3px 纯黑
  • 相邻元素阴影方向一致
  • 主色只出现在按钮、徽章、强调标记
  • 375px 宽下无横向滚动

03Components
Button: black fill, white text, 3px black border,
hover offset (2,2)
Card: white, 3px border, hard shadow, hover up 4px
Input: 3px black border, blue 2px outline on focus
Nav: 3px black rule at bottom
04Forbidden
  • No shadow with blur greater than 0
  • No gradients of any kind
  • No ambiguous 4-8px radius
  • No low-saturation palettes
05Acceptance
  • Every visible border is 3px solid black
  • All shadows share the same offset direction
  • Accent appears only on buttons, badges, marks
  • No horizontal scroll at 375px
