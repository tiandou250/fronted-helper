02 结构化 Prompt
01

视觉 Token

Tokens
边框：2.5px solid currentColor，全站统一
圆角：卡片与按钮 0，徽章 999px
阴影：5px 5px 0 currentColor，零模糊，全站唯一
字阶：15 / 17 / 21 / 30 / 46 / 62
间距基数：8px
动效：140ms，仅用于 hover 位移
配色：不指定，全部继承项目主色与文字色
02

布局与响应式

Layout
移动优先，三档断点：
· <768px：单列，留白 16px，区块间距 48px
· 768–1279px：最大宽 960px，特性区 2 列
· ≥1280px：最大宽 1200px，特性区 3 列

区块顺序：导航 → Hero → 特性 → 步骤 → 价格 → 页脚
所有区块用 Grid 定义列数，禁止写死容器宽度
Hero 留白：移动 40px / 桌面 88px
03

组件与响应式行为

Components
按钮：最小触控区 44×44px；<480px 时主按钮全宽堆叠
卡片：1 列 → 768px 起 2 列 → 1280px 起 3 列
输入框：高度 ≥ 48px，字号 ≥ 16px（防 iOS 聚焦缩放）
导航：≥768px 横向链接；<768px 折叠为汉堡 + 全屏抽屉
表格：<768px 每行改为一张堆叠卡，不做横向滚动
04

禁止事项

Forbidden
  • 不要任何模糊半径大于 0 的阴影
  • 不要使用渐变，三种全部禁止
  • 不要 4–8px 的暧昧圆角
  • 不要用固定 px 写死容器宽度
  • 不要出现横向滚动条
  • 移动端触控区不得小于 44px
05

验收标准

Acceptance
  • 375 / 768 / 1440 三档均无横向滚动
  • 所有可见边框粗细一致，阴影方向一致（右下）
  • 移动端所有可点元素 ≥ 44×44px
  • 导航在 375px 下折叠为汉堡，可正常展开
  • 关闭图片后页面依然成立
01

Visual Tokens

Tokens
Border: 2.5px solid currentColor everywhere
Radius: 0 for cards and buttons, 999px badges
Shadow: 5px 5px 0 currentColor, zero blur, only shadow
Type scale: 15 / 17 / 21 / 30 / 46 / 62
Spacing base: 8px
Motion: 140ms, hover offset only
Color: inherit project palette, no fixed hex
02

Layout & Responsive

Layout
Mobile first, three breakpoints:
- below 768: 1 col, 16px gutter, 48px block gap
- 768-1279: max 960px, features in 2 cols
- 1280 up: max 1200px, features in 3 cols

Order: nav, hero, features, steps, pricing, footer
Define columns with Grid, never hardcode width
Hero padding: 40px mobile / 88px desktop
03

Components

Components
Button: min hit area 44x44px; full width below 480px
Card: 1 col, 2 cols from 768, 3 cols from 1280
Input: height 48px or more, font-size 16px min
Nav: inline links from 768; hamburger drawer below
Table: below 768 each row becomes a stacked card
04

Forbidden

Forbidden
  • No shadow with blur greater than 0
  • No gradients of any kind
  • No ambiguous 4-8px radius
  • No fixed pixel container widths
  • No horizontal scrollbar at any width
  • No tap target smaller than 44px
05

Acceptance

Acceptance
  • No horizontal scroll at 375, 768, or 1440
  • All borders share one weight, all shadows one direction
  • Every tappable element is at least 44x44px on mobile
  • Nav collapses to a hamburger at 375 and opens
  • Page still works with images disabled
