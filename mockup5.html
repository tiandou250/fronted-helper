动效工具

主流页面在用的交互动效。鼠标移到演示区就能看到真实效果，下面的代码可以直接抄。所有动效控制在 300ms 以内——超过 300ms 用户就开始觉得卡。

悬停抬升

200ms · cubic-bezier(.16,1,.3,1)
.btn:hover { transform: translateY(-6px); box-shadow: 0 10px 20px rgba(0,0,0,.15); }

按压反馈

120ms · ease-out
.btn:active { transform: scale(.94); }

下划线滑入

280ms · 从中心展开
.link::after { width: 0; transition: width .28s; } .link:hover::after { width: 100%; }

描边浮现

300ms · 由内向外
.btn::before { transform: scale(.86); opacity: 0; } .btn:hover::before { transform: scale(1); opacity: 1; }

涟漪扩散

600ms · 从点击点计算
// 在点击坐标创建一个圆 rp.style.left = x + 'px'; rp.style.top = y + 'px'; rp.style.animation = 'rip .6s';

图标形变

300ms · 汉堡转叉
.bars i:nth-child(1) { transform: translateY(7.5px) rotate(45deg); } .bars i:nth-child(2) { opacity: 0; }

骨架屏扫光

1.6s · 无限循环
::after { background: linear-gradient( 90deg, transparent, #fff, transparent); animation: shim 1.6s infinite; }

呼吸脉冲

1.6s · 加载中
@keyframes pulse { 0%,100% { opacity:.25; transform:scale(.85); } 50% { opacity:1; transform:scale(1); } }

3D 倾斜

250ms · 跟随鼠标
.card:hover { transform: perspective(400px) rotateX(8deg) rotateY(-12deg); }

悬浮漂浮

3.4s · 循环
装饰元素
@keyframes float { 0%,100% { transform: translateY(0); } 50% { transform: translateY(-9px); } }

01

视觉 Token

Tokens
边框：2.5px solid currentColor，全站统一
圆角：卡片与按钮 0，徽章 999px
阴影：5px 5px 0 currentColor，零模糊，全站唯一

02

布局与响应式

Layout
移动优先，三档断点：
小于 768px：单列，左右留白 16px，区块间距 48px
768 至 1279px：最大宽 960px，特性区 2 列，留白 32px
1280px 及以上：最大宽 1200px，特性区 3 列，留白 48px

区块顺序：导航 至 Hero 至 特性 至 步骤 至 价格 至 页脚
所有区块用 CSS Grid 定义列数，禁止写死容器宽度
Hero 上下留白：移动 40px，桌面 88px
03

组件与响应式行为

Components
按钮：最小触控区 44×44px；小于 480px 时主按钮全宽、纵向堆叠
卡片：1 列，768px 起 2 列，1280px 起 3 列
输入框：高度至少 48px，字号至少 16px，防 iOS 聚焦缩放
导航：768px 起横向链接，小于 768px 折叠为汉堡加全屏抽屉
表格：小于 768px 时每一行改为一张堆叠卡片，不做横向滚动
04

禁止事项

Forbidden
  • 不要使用任何模糊半径大于 0 的阴影
  • 不要使用渐变，三种全部禁止
  • 不要使用 4 至 8px 的暧昧圆角
  • 不要用固定像素写死容器宽度
  • 不要出现横向滚动条
  • 移动端触控区不得小于 44px
05

验收标准

Acceptance
  • 375、768、1440 三档均无横向滚动
  • 所有可见边框粗细一致，阴影方向一致，右下偏移
  • 移动端所有可点元素不小于 44×44px
  • 导航在 375px 下折叠为汉堡，且可正常展开
  • 关闭图片后页面依然成立

02

Layout & Responsive

Layout
Mobile first, three breakpoints:
below 768: single column, 16px gutter, 48px block gap
768 to 1279: max 960px, features in 2 columns
1280 and up: max 1200px, features in 3 columns

Order: nav, hero, features, steps, pricing, footer
Define columns with CSS Grid, never hardcode width
Hero padding: 40px mobile, 88px desktop
03

Components

Components
Button: min hit area 44x44px; full width below 480px
Card: 1 column, 2 from 768, 3 from 1280
Input: 48px height minimum, 16px font minimum
Nav: inline links from 768; hamburger drawer below
Table: below 768 each row becomes a stacked card
04

Forbidden

Forbidden
  • No shadow with blur greater than 0
  • No gradients of any kind
  • No ambiguous 4 to 8px radius
  • No fixed pixel container widths
  • No horizontal scrollbar at any width
  • No tap target smaller than 44px
05

Acceptance

Acceptance
  • No horizontal scroll at 375, 768, or 1440
  • All borders share one weight, all shadows one direction
  • Every tappable element is at least 44x44px on mobile
  • Nav collapses to a hamburger at 375 and opens
  • Page still works with images disabled
