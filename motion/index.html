动效工具

116 个主流动效，分 12 类。鼠标移到演示区就能看到真实效果，下面的代码可以直接抄。 一条硬规矩：响应型动效不超过 300 毫秒——超过用户就开始觉得卡。
2026 年该补的三块也补上了：原生 CSS（scroll-driven 动画、View Transitions、@property）、三维空间（CSS 3D、透视、景深）、数据可视化（图表生长、数字缓动）—— 这三块是目前最常用、也最少人写进 prompt 的。

路由转场

420ms · 旧页淡出 新页上移
Route Transition

换页时旧内容先淡出 120ms，新内容再从下方 24px 处淡入。关键是两者不重叠——重叠会出现「两个页面同时存在」的错乱感。

// exit: opacity 1→0, 120ms // enter: opacity 0→1, translateY 24→0 await exit(); await enter();

共享元素过渡

460ms · 位置与尺寸同时插值
Shared Element

缩略图放大成详情页头图。用 FLIP：先量旧位置，再量新位置，用 transform 从旧位置过渡到新位置。做对了会有「东西飞过去」的感觉。

const first = el.getBoundingClientRect(); // 布局变化后 const last = el.getBoundingClientRect(); // transform: first → last，再播放

滚动叙事

跟随滚动 · 章节被钉住
Scroll Story

苹果产品页的做法：一段区域 position: sticky 钉住，滚动只推进内部阶段。用户以为在往下翻，其实画面在原地演进。

.stage { position: sticky; top: 0; height: 100vh; } // 父容器高度 = 阶段数 × 100vh // 用 scrollY 百分比切换阶段

章节吸附

滚动结束时吸附 400ms
Section Snap

滚到哪一章就自动对齐到那一屏。用 scroll-snap-type，不要手写 scrollTo——手写会在触控板双指滚动时打架。

.page { scroll-snap-type: y mandatory; overflow-y: scroll; } .section { scroll-snap-align: start; }

滚动缩放

跟随滚动 · scale 1 → 1.8
Scroll Zoom

向下滚，首屏主视觉缓慢放大直到铺满屏幕，作为进入正文的过渡。缩放幅度超过 2 倍就开始糊了。

const p = clamp(scrollY / heroHeight, 0, 1); hero.style.transform = `scale(${1 + p * 0.8})`;

横向整页

跟随纵向滚动
Horizontal Scroll

纵向滚动驱动横向位移，页面横着走。必须保证不抢系统横向手势，移动端要谨慎——容易和浏览器返回手势冲突。

.track { transform: translateX(calc(var(--y) * -1px)); } // 竖向滚动的 scrollY 映射成横向偏移

全屏菜单

520ms · 圆形从按钮扩散
Fullscreen Menu

点汉堡，一个圆从按钮位置扩散铺满全屏。用 clip-path: circle() 从 0 到 150%，比整块淡入有方向感。

.menu { clip-path: circle(0% at 92% 8%); transition: clip-path .52s; } .menu.open { clip-path: circle(150% at 92% 8%); }

加载到内容

900ms · 进度条走完后让位
Loader to Content

加载条走到 100% 后向上滑走，内容同时从下方升起。两件事必须同时发生，否则中间会闪一帧空白。

loader.style.transform = 'translateY(-100%)'; content.style.transform = 'translateY(0)'; // 同一个 requestAnimationFrame 里触发

卡片叠压

跟随滚动
Sticky Stack

多张卡片依次粘在顶部，后一张压住前一张并让它缩小 4%。做产品特性介绍最有效——用户会一直滚着看下一张。

.panel { position: sticky; top: 64px; } .panel:nth-child(2) { top: 88px; } // 每张顶部偏移递增 24px

滚动同步文字

跟随滚动
Text Scrub

一段长文案，每滚一点就亮一行，像被读出来。用 background-clip: text 配合渐变位置，一行代码就能实现。

.para { background: linear-gradient(90deg, #2b2b2b var(--p), #c8c8c8 var(--p)); background-clip: text; color: transparent; }

幕布转场

620ms
Curtain Wipe

一块实色从下往上盖住，再从上方移走露出新页面。传统编辑器感的转场，比淡入有仪式感。

.curtain { transform: translateY(100%); } // 盖上：0 → 0% // 揭开：0% → -100%

跟随光标扩展

跟随鼠标 · 半径 0 → 140px
Cursor Reveal

鼠标位置开一个圆形窗口，透过它看到另一张图。作品集网站爱用，成本低但有惊喜感。

.overlay { clip-path: circle(140px at var(--x) var(--y)); }

分屏揭示

700ms · 两片对开
Split Reveal

一块遮罩从中间向两侧分开，露出底下的内容。比淡入更有「揭幕」的仪式感，适合品牌首页开场。

.left { transform: translateX(0); } .right { transform: translateX(0); } .open .left { transform: translateX(-100%); } .open .right { transform: translateX(100%); }

图片序列

跟随滚动 · 帧索引映射
Image Sequence

把滚动位置映射成帧序号，滚动就像在拖时间轴。产品拆解、旋转展示都用这套，本质是「滚动当播放器」。

const frame = Math.floor( (scrollY / total) * frames.length); canvas.drawImage(frames[frame], 0, 0);

侧边跟随导航

跟随滚动 · 高亮切换 200ms
Scroll Spy

长文页右侧一列小点，滚到哪一节哪个点就亮。用 IntersectionObserver 监听每个章节，不要算 scrollY 区间。

new IntersectionObserver(entries => { entries.forEach(e => { if (e.isIntersecting) setActive(e.target.id); }); }, { rootMargin: '-45% 0px' }).observe(sec);

首屏收缩

420ms · 高度 96 → 56px
Shrink Header

滚过首屏后，大标题导航缩成一条细条。关键是缩的同时把 logo 从居中移到左侧，用户不会觉得「换了个页面」。

header.classList.toggle('small', scrollY > 80); .small { height: 56px; } .small .logo { transform: scale(.7) translateX(0); }

缩放穿越

780ms · scale 1 → 6 并淡出
Zoom Through

点一张卡片，整页朝那张卡片放大并穿过去，落地就是详情页。迪士尼式转场，做对了很惊艳，做重了很晕。

wrap.style.transformOrigin = `${x}px ${y}px`; wrap.style.transform = 'scale(6)'; wrap.style.opacity = '0';

网格展开

520ms · 两端插值
Grid Expand

缩略图从网格里的位置，长成全屏详情。和共享元素类似，但对象是「容器」——宽高同时从格子尺寸过渡到视口尺寸。

// First: 格子的 rect // Last: 全屏的 rect // 用 transform 从 First 播到 Last

倾斜滚动

跟随滚动 · 最大 ±5deg
Skew on Scroll

滚动时内容轻微倾斜，像被速度甩了一下。角度必须跟着滚动速度而不是位置，松手后回正，否则会一直歪着。

const skew = clamp(velocity * 0.05, -5, 5); list.style.transform = `skewY(${skew}deg)`;

多层视差

跟随滚动 · 三层不同速度
Layered Parallax

背景 0.2 倍速、中景 0.5 倍速、前景 1 倍速。层数超过三层就开始卡，也没人看得出区别。

.layer-1 { transform: translateY(calc(var(--y) * 0.2)); } .layer-2 { transform: translateY(calc(var(--y) * 0.5)); } .layer-3 { transform: translateY(calc(var(--y) * 1)); }

光标拖尾

跟随 · 带延迟队列
Cursor Trail

一串跟随光标的元素，每个都比前一个慢一点，形成拖尾。实现方式不是给每个元素都监听 mousemove——那样会掉帧。正确做法是监听一次，缓存坐标，用 requestAnimationFrame 让每个元素按比例追赶当前位置。

const dots = [...document.querySelectorAll('.dot')]; let x = 0, y = 0; dots.forEach((d, i) => d._t = i * 0.06); function loop() { x += (mx - x) * 0.2; y += (my - y) * 0.2; dots.forEach((d, i) => { const k = 1 - d._t * 1.4; d.style.transform = `translate(${x * k}px, ${y * k}px)`; }); requestAnimationFrame(loop); }

故障转场

RGB 错位 · 400ms
Glitch Transition

用三层彩色副本叠在原元素上，各层用不同 clip-path 位置并快速抖动，做出信号错位的感觉。做的时候要用 steps() 步进而不是平滑曲线——故障是离散跳变，不是渐变。位置抖动幅度控制在 2-4px 就够，大了会看不清内容。

.glitch { position: relative; animation: jitter .4s steps(2) 3; } .glitch::before, .glitch::after { content: attr(data-text); position: absolute; inset: 0; clip-path: inset(0 0 60% 0); } @keyframes jitter { 0% { transform: translate(0); } 25% { transform: translate(-3px, 1px); } 50% { transform: translate(2px, -2px); } 75% { transform: translate(-1px, 2px); } }

变形菜单

形状插值 · 500ms
Morphing Menu

按钮点击后变形展开成菜单面板。CSS 本身没法插值不同形状，得靠 clip-path 变形或者 SVG 的 path d 插值。clip-path 方案最简单：圆形裁切区域从按钮位置扩展到整个面板，配合 opacity 淡入内容。

.menu { clip-path: circle(24px at 50% 50%); transition: clip-path .5s cubic-bezier(.16,1,.3,1); } .menu.open { clip-path: circle(150% at 50% 50%); }

反向滚动列

多列反向 · 各自独立
Counter Scroll Columns

多列内容以不同速度甚至相反方向滚动，制造出「洗衣机滚筒」的视觉趣味。反向的那列要用负的动画时长或把 keyframes 倒过来。列间距要够宽，不然内容会互相穿插。

.col { animation: scrollUp 20s linear infinite; } .col:nth-child(even) { animation-direction: reverse; } @keyframes scrollUp { from { transform: translateY(0); } to { transform: translateY(-50%); } }

布局重排

420ms · 每个元素独立插值
Layout FLIP

列表从网格切到列表视图，每个元素各自飞向新位置。用 FLIP 记录前后位置再补间，比重新渲染一遍高级得多。

// First: 记录所有 item 的 rect // Last: 布局变后重新记录 // Invert: 先用 transform 回到旧位 // Play: 移除 transform，让它飞回去

拖拽排序

跟手 + 200ms 归位
Drag Reorder

拖动时被拖项跟手且放大 1.04，其他项用 transform 让位（不要改 DOM 顺序，会掉帧）。松手后再提交顺序。

// 拖动中只改 transform el.style.transform = `translateY(${dy}px)`; // 其他项自动上移/下移一格

滑动卡片

跟手 + 320ms 甩出
Swipe Card

拖动判断方向和距离，超过阈值就朝该方向甩出去并淡出。阈值设成卡片宽度的 30% 最符合直觉。

if (Math.abs(dx) > width * 0.3) { el.style.transform = `translateX(${dx * 2}px) rotate(${dx * 0.06}deg)`; }

下拉刷新

跟手 · 阻尼 0.4
Pull to Refresh

下拉时内容跟手但速度减半（阻尼），超过 64px 松手才触发刷新。阻尼系数 0.4 最舒服，1.0 会显得太硬。

const damped = Math.max(0, dy) * 0.4; list.style.transform = `translateY(${damped}px)`;

标签滑动指示器

280ms · 位移 + 宽度同时变化
Tab Indicator

下划线跟着当前标签滑动，宽度也跟着变。别用 left 动画，用 transform: translateX 才不会触发重排。

bar.style.width = tab.offsetWidth + 'px'; bar.style.transform = `translateX(${tab.offsetLeft}px)`;

手风琴组

340ms · 同时开只留一个
Accordion Group

点开一个，其他自动收起。同一时间只允许一个展开，否则页面会被撑得很长、用户找不到位置。

items.forEach(i => i !== current && i.close()); current.toggle();

筛选过渡

380ms · FLIP
Filter Transition

切换筛选条件时，保留下来的卡片飞到新位置，被筛掉的淡出。直接重渲染会「闪一下」，必须用 FLIP 补间。

// 记录旧位置 → 改 DOM → 记录新位置 // 用 transform 从旧位置倒推，再播放归零

表格行展开

320ms
Row Expand

点一行，下方展开详情区。展开时该行要高亮，且不能把相邻行挤得跳——用独立的详情行而不是往单元格里塞。

tr.classList.add('open'); tr.after(detailRow); // 独立的详情行 detailRow.style.height = h + 'px';

无限加载

触底 200px 预加载
Infinite Scroll

滚到底部前 200px 就开始加载，不要等真到底——等到底再加载用户会看到一瞬空白。加载中用骨架占位。

if (scrollTop + clientH > scrollH - 200) load();

通知堆叠

320ms · 新通知从下方推入
Toast Stack

多条通知从下往上堆，旧的往上移并缩小。最多同时显示 3 条，超出的排队，否则会盖满屏幕。

toasts.map((t, i) => ({ transform: `translateY(${-i * 64}px) scale(${1 - i * 0.04})` }));

悬停抬升

200ms · cubic-bezier(.16,1,.3,1)

最通用的一种，按钮和卡片都能用。关键是要同时改位移和阴影，只改其中一个会显得飘。

.btn:hover { transform: translateY(-8px); box-shadow: 10px 10px 22px #b3b3b3, -10px -10px 22px #fff; }

按压回弹

100ms · ease-out

触屏时代最重要的反馈。鼠标点击和手指点击都需要它，否则用户不确定自己点到了没有。

.btn:active { transform: scale(0.93); } /* 回弹靠 100ms 的短过渡 */

下划线滑入

280ms · 从中心展开

链接的经典写法。从中心向两侧展开比从左往右更有张力，也比整条直接出现更细腻。

.link::after { width: 0; left: 50%; transform: translateX(-50%); transition: width .28s; } .link:hover::after { width: 100%; }

描边浮现

300ms · 由内向外

透明的边框从 0.86 倍放大到原尺寸，同时淡入。适合给“无边界”的按钮加确认感。

.btn::before { border: 2px solid #111; opacity: 0; transform: scale(.86); } .btn:hover::before { opacity: 1; transform: scale(1); }

涟漪扩散

600ms · 从点击坐标计算

Material Design 的招牌。必须按真实点击位置生成圆，居中扩散会显得假。

rp.style.left = (e.clientX - r.left) + 'px'; rp.style.top = (e.clientY - r.top) + 'px'; rp.style.animation = 'rip .6s ease-out';

图标形变

300ms · 汉堡转叉

三条线里让第二条消失、上下两条旋转并平移。位移量必须精确等于线距的一半。

.bars i:nth-child(1) { transform: translateY(7.5px) rotate(45deg); } .bars i:nth-child(2) { opacity: 0; } .bars i:nth-child(3) { transform: translateY(-7.5px) rotate(-45deg); }

磁吸跟随

250ms · 跟随鼠标

按钮朝鼠标方向偏移一小段距离（约 0.25 倍），松手回中。大厂官网爱用，但移动端不要用。

const dx = (e.clientX - cx) * 0.25; const dy = (e.clientY - cy) * 0.25; el.style.transform = `translate(${dx}px, ${dy}px)`;

聚焦光晕

250ms

用 box-shadow 做一圈外发光。键盘可达性必备——键盘用户看不到鼠标位置，只能靠它。

.btn:hover, .btn:focus-visible { box-shadow: 0 0 0 4px rgba(43,43,43,.12), var(--up-sm); }

原生滚动进度条

跟随滚动 · 零 JS

最该用原生实现的经典效果。用 animation-timeline: scroll() 绑到根滚动容器，进度条随滚动自动生长，完全不用 scroll 事件监听。性能比 JS 版本好一截，因为跑在合成线程上。这是 2026 年最值得切换过去的一个小改动。

@supports (animation-timeline: scroll()) { .bar { position: fixed; top: 0; left: 0; height: 3px; width: 100%; background: #111; transform-origin: 0 50%; animation: grow linear; animation-timeline: scroll(); } } @keyframes grow { to { transform: scaleX(1); } }

原生视口错开

按行错开 · 纯 CSS
1
2
3

卡片列表的错开淡入，用 view() + animation-range 就能做，连 IntersectionObserver 都省了。错开的关键是给每张卡不同的 animation-range 起点——用 calc 和 sibling-index() 可以不写 nth-child。这是原生滚动驱动最实用的一个变体。

.card { animation: fade-up linear both; animation-timeline: view(); animation-range: entry 0% entry 35%; } .card:nth-child(3n+2) { animation-range: entry 5% entry 40%; } .card:nth-child(3n+3) { animation-range: entry 10% entry 45%; }

横向吸附画廊

吸附对齐 · 纯 CSS
01
02
03
04
05

横滑卡片列表的标准做法：scroll-snap-type: x mandatory + 每张卡 scroll-snap-align: start。用 CSS 实现比 JS 滚动监听可靠得多，触控板双指滚动时不会打架。注意一定要设 scroll-snap-stop: always，否则快速滑动会连跳好几张。

.rail { display: flex; overflow-x: auto; scroll-snap-type: x mandatory; scroll-snap-stop: always; } .card { flex: 0 0 280px; scroll-snap-align: start; }

粘性进度导航

吸顶 · 随滚动变色
导航
吸顶导航的底边会随滚动显出一条进度线，指示当前阅读位置。

导航吸顶后，底边出现一条进度线，指示当前读到哪。这个组合的关键是 position: sticky 而不是 fixed——sticky 保留了文档流，不会遮挡内容。进度线可以用 scaleX 过渡，比改 width 便宜得多。

.nav { position: sticky; top: 0; } .progress { transform-origin: 0 50%; transition: transform .12s linear; /* JS 里更新 scaleX(scrollRatio) */ }

进视口淡入

620ms · 位移 28px
↧

最基础的滚动动效。用 IntersectionObserver 判断，不要监听 scroll 事件（性能差十倍）。

new IntersectionObserver(([en]) => { if (en.isIntersecting) el.classList.add('in'); }, { threshold: 0.2 }).observe(el);

视差

跟随滚动 · 位移 ±12px
◐

背景层比前景层慢。幅度一大就晕，安全区间是可见位移不超过 20px。

.bg-layer { transform: translateY( calc(var(--scroll) * 0.15)); }

粘性叠层

跟随滚动

position: sticky + 逐层上浮，做出卡片堆叠的感觉。每层缩 4%、错开 280ms 最舒服。

.panel { position: sticky; top: 80px; } .panel:nth-child(2) { top: 96px; }

滚动进度条

实时

顶部一条 3px 的线，宽度等于阅读进度。长文页面必备，成本极低。

const p = scrollY / (document.body.scrollHeight - innerHeight); bar.style.transform = `scaleX(${p})`;

数字滚动

900ms · ease-out
12,480

统计数字从 0 滚到目标值。必须用 tabular-nums，否则数字宽度变化会让整行抖动。

.num { font-variant-numeric: tabular-nums; } // requestAnimationFrame 逐帧插值

无限滚动条

9s · linear 循环

内容复制一份，轨道整体左移自身宽度后瞬间回到原位。用 CSS 就够，别用 JS。

.track { animation: track 9s linear infinite; } @keyframes track { to { transform: translateX(-100%); } }

编辑式下划线

从右向左 · 400ms
编辑设计

杂志排版的经典手法：下划线从右端往左画出，最后停稳在词尾。要点是 transform-origin 设成右边，scaleX 从 0 长到 1。用 cubic-bezier 加一点回弹，比线性更有手感。

.title { position: relative; } .title::after { content: ''; position: absolute; left: 0; right: 0; bottom: -4px; height: 3px; background: currentColor; transform: scaleX(0); transform-origin: right center; transition: transform .4s cubic-bezier(.16,1,.3,1); } .title:hover::after { transform: scaleX(1); }

等宽数字滚动

数字切换 · 200ms
¥ 1,280.00

价格、计数器这类会频繁变化的数字，必须用 font-variant-numeric: tabular-nums，否则每次变化字宽都会跳，整行跟着左右晃。等宽数字是表格和仪表盘的基本功，忘了它整页都显得业余。

.price { font-variant-numeric: tabular-nums; font-feature-settings: 'tnum' 1; transition: opacity .2s; } .price.updating { opacity: .4; }

逐词浮现

原生滚动驱动 · 入场

2026 年最该掌握的 CSS 新能力。用 animation-timeline: view() 把动画绑到元素进入视口的进度上，完全不写一行 JavaScript，浏览器在合成线程跑，不占主线程。关键前提：必须用 @supports 包起来，否则 Safari 17 和旧版 Firefox 上内容会永远不可见。

路径描边生长

stroke-dashoffset · 1.2s

SVG 最经典的动画。stroke-dasharray 设成路径长度，dashoffset 从长度移到 0，线条就「画」出来了。关键技巧：pathLength="1" 可以把归一化，dasharray 写成 1，不用测真实路径长度，字形图标也能通用。

.icon path { pathLength: 1; stroke-dasharray: 1; stroke-dashoffset: 1; animation: draw 1.2s ease forwards; } @keyframes draw { to { stroke-dashoffset: 0; } }

手写签名

逐段描出 · 2s

手写体签名是最能体现「画出来」这四个字的应用。做法是把签名拆成多条 path，按顺序延迟启动，每条线用 dashoffset 画出。要给每条 path 加 animation-delay，间隔大约 180ms，手写才有节奏。

.sig path { stroke-dasharray: 1; stroke-dashoffset: 1; animation: draw .8s ease forwards; } .sig path:nth-child(2) { animation-delay: .18s; } .sig path:nth-child(3) { animation-delay: .36s; }

路径形变

d 属性插值 · 600ms

两个 path 之间做形变，前提是两者命令数量和类型完全一致——M 对 M、L 对 L。多一个点就形变失败。点数不同时要先在设计工具里补齐控制点。Easing 用 ease-in-out 双向最自然。

.shape path { d: path('M0 0 L100 0 L100 100 L0 100 Z'); transition: d .6s ease-in-out; } .shape:hover path { d: path('M50 0 L100 50 L50 100 L0 50 Z'); }

逐字 · 60ms 间隔

比 HTML 逐字效果好在两点：可以做任意路径排版（沿弧线、沿波浪），并且每个字是独立矢量可以单独变形。实现方式是把文字转成 path，再给每个 path 加延迟动画。

.glyph { opacity: 0; animation: rise .5s ease forwards; } .glyph:nth-child(1) { animation-delay: 0s; } .glyph:nth-child(2) { animation-delay: .06s; } @keyframes rise { from { opacity: 0; transform: translateY(20px); } }

揭示

用 clip-path 的 inset 值做揭示，比 width/height 动画性能好得多——它不触发布局。对比：用 width 动画会每帧重新布局，用 clip-path 只在合成层跑。数值上写成百分比最稳。

.reveal { clip-path: inset(0 100% 0 0); transition: clip-path .7s cubic-bezier(.16,1,.3,1); } .reveal.in { clip-path: inset(0 0 0 0); }

给 stroke 挂一个 linearGradient，然后动 gradientTransform 或者用 animate 改 stop 的 offset。渐变本身不动、只有描边在动会显得假——要么让渐变跟着线条走，要么两者都动。

加载中的图标绘制

循环 · 描边生长

加载态最有说服力的做法不是转圈，而是一个图标在反复「画自己」——用户知道内容正在成形。实现是 dashoffset 循环，配合 pathLength 归一化，任何图标都能用。

.loader path { pathLength: 1; stroke-dasharray: 1; stroke-dashoffset: 1; animation: draw 1.5s ease-in-out infinite; } @keyframes draw { 0% { stroke-dashoffset: 1; } 50% { stroke-dashoffset: 0; } 100% { stroke-dashoffset: -1; } }

SVG 液态变形

多边形变形 · 8s 循环

用 SMIL 的 animate 元素做多边形变形，浏览器原生支持，不用 JS。关键是对应点数量一致，且围绕中心分布。SVG 路径的平滑是自动的，节点少一点反而更流畅。

<path> <animate attributeName="d" dur="8s" repeatCount="indefinite" values="M0,0 L10,0 L10,10 L0,10 Z; M5,0 L15,5 L5,15 L-5,5 Z" /> </path>

图表生长

柱状依次升起 · 800ms

图表入场最忌讳所有柱子同时长出来，观众来不及看清每根柱子的高度。用 animation-delay 按索引递增错开，间隔 60-80ms，十几根柱子也就一秒出头。注意 transform-origin 必须在底部。

.bar { transform-origin: bottom; animation: grow .8s cubic-bezier(.16,1,.3,1) backwards; } .bar:nth-child(2) { animation-delay: .07s; } .bar:nth-child(3) { animation-delay: .14s; } @keyframes grow { from { transform: scaleY(0); } }

折线绘制

1.6s · 逐点展开

折线图最有仪式感的入场：一笔画出来。用 stroke-dashoffset 配合 pathLength="1"，再在末端放一个圆点跟着线头移动。线画完后圆点弹一下，数据点就自然出现了。

.line { pathLength: 1; stroke-dasharray: 1; stroke-dashoffset: 1; animation: draw 1.6s ease-out forwards; } @keyframes draw { to { stroke-dashoffset: 0; } }

数字缓动

1.2s · easeOutExpo
12,480

数字滚动别用线性插值——线性到一半速度不变，感觉像在跳表。要用 easeOutExpo 这类指数缓动，开头快、末尾慢，才有「停下来」的重量感。同时记得用 toLocaleString 加千分位。

const ease = t => t === 1 ? 1 : 1 - Math.pow(2, -10 * t); let v = 0; const step = () => { v = Math.round(target * ease(v / target)); el.textContent = v.toLocaleString(); if (v < target) requestAnimationFrame(step); };

环形进度填充

跟随滚动 · stroke-dashoffset

环形进度用 stroke-dasharray 的「剩余段」控制，dashoffset=0 是满圈。把 dasharray 写成 circumference，offset 从 circumference 减到 0 就画满了。做成跟随滚动的版本体验更好——用户滚到哪，进度走到哪。

.ring { stroke-dasharray: 301.6; stroke-dashoffset: 301.6; transition: stroke-dashoffset 1.2s ease-out; } .ring.in { stroke-dashoffset: 75; } /* 25% */

横向条形图的动态版本，宽度过渡用 transition 而不是 keyframes，这样数据更新时会平滑过渡而不是重新播放动画。做排行榜实时刷新时这一点很关键——否则每次刷新整张图都在闪。

.row { transition: width 1s cubic-bezier(.16,1,.3,1); } /* 数据更新时只改 width，不重播 keyframes */

迷你趋势线

入场绘制 · 900ms

表格里的迷你趋势图，宽度只有 80px 左右，不能加复杂动效。路径绘制 + 末尾圆点就够。数据点超过 20 个时直接用 polyline 而不是平滑曲线，否则会失真。

.spark { pathLength: 1; stroke-dasharray: 1; animation: draw .9s ease-out; } .spark circle { animation: pop .3s ease .9s backwards; }

热力格点亮

按数值排序错开

热力图要按数值从大到小依次点亮，而不是按坐标顺序——先亮最热的格子，观众第一眼就知道峰值在哪。实现方式是给格子排序后设置 delay，而不是靠 CSS 的 nth-child。

cells.sort((a, b) => b.value - a.value) .forEach((c, i) => c.style.animationDelay = i * 25 + 'ms');
