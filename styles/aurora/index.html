02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景 #07070B，接近纯黑但保留一点冷调
  • 色晕：3 个大半径径向渐变（靛蓝 / 品红 / 青），blur 60–120px
  • 文字：白色 + 60% 白，标题可用渐变裁切文字
  • 边框：1px rgba(255,255,255,.08)，只做极轻分区
  • 圆角：卡片 16px，按钮 8px
  • 光晕层必须 pointer-events: none
02

布局与响应式

Layout & Responsive
  • 单列居中，最大宽 1120px，留白 24px
  • 色晕铺在首屏背后，向下逐渐消失
  • Hero 居中，标题最多两行
  • 移动端色晕半径减半，避免糊成一团
03

组件与响应式行为

Components
  • 按钮：白底黑字实心，或 1px 白边透明底
  • 卡片：rgba(255,255,255,.03) + 1px rgba(255,255,255,.08)
  • 输入框：深底 + 1px 边框，focus 时边框变亮
  • 导航：透明，滚动后加背景模糊
04

禁止事项

Forbidden
  • 不要使用纯黑 #000，必须有极轻微冷调
  • 不要给色晕加硬边或描边
  • 不要在同一屏放超过 3 个色晕
  • 不要用高饱和纯色，全部要模糊软化
  • 不要让色晕盖住正文区域
  • 不要用玻璃拟态的强边高光
05

验收标准

Acceptance
  • 色晕边缘完全柔化，无可见边界
  • 正文区域对比度 ≥ 7:1
  • 色晕不影响文字可读性
  • 首屏不出现 3 个以上色晕
