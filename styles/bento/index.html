02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景 #F7F7F5，格子 #FFFFFF，深色格 #111111
  • 圆角：格子 16–20px，统一
  • 阴影：0 1px 3px rgba(0,0,0,.06)，极轻
  • 格子内边距 24px，格子间距 12px
  • 字阶：13 / 15 / 20 / 28 / 40
  • 色块只能出现在深色格与图标底
02

布局与响应式

Layout & Responsive
  • 12 列网格，最大宽 1200px，间距 12px
  • 首屏必须有一个跨 2 行或 2 列的『主格』
  • 格子尺寸只用 1×1 / 2×1 / 1×2 / 2×2 四种，不要出现 3×2
  • 移动端：全部退化为 1×1 单列堆叠
03

组件与响应式行为

Components
  • 按钮：小圆角实心，放在格子内部右下角
  • 格子：白底圆角，内容顶部对齐
  • 输入框：放在独占格子内，占满宽度
  • 图标：统一尺寸的方块或圆形色底
04

禁止事项

Forbidden
  • 不要让所有格子同样大小
  • 不要使用超过 2 种格子尺寸组合在同一屏
  • 不要给格子加深色阴影
  • 不要在格子内塞超过 3 个信息层级
  • 不要使用不规则形状
  • 移动端不要保留多列
05

验收标准

Acceptance
  • 首屏存在至少一个跨格
  • 格子尺寸种类 ≤ 4
  • 移动端无横向滚动
  • 格子间距横纵一致
