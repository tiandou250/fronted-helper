02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 边框 2.5px solid currentColor，全站统一
  • 圆角：卡片与按钮 0，徽章 999px
  • 阴影 5px 5px 0 currentColor，零模糊，全站唯一
  • 字阶 15 / 17 / 21 / 30 / 46 / 62，标题字距 -0.035em
  • 行高：正文 1.7，标题 0.95
  • 配色：不指定色值，继承项目主色；只要求主色饱和度高
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1200px，左右留白 24px
  • 区块顺序：导航 → Hero → 特性三宫格 → 步骤 → 价格 → 页脚
  • Hero 上下留白 88px，区块间距 80px
  • 移动端：单列，特性卡纵向堆叠，留白 16px
03

组件与响应式行为

Components
  • 按钮：实心填充 + 2.5px 边 + 硬阴影，hover 位移 (2,2) 且阴影缩到 3px
  • 卡片：白底 2.5px 边 + 硬阴影，hover 上移 4px
  • 输入框：白底 2.5px 边，focus 时加 2px 外描边
  • 导航：底部 3px 实线分隔，链接 hover 出现 3px 下划线
04

禁止事项

Forbidden
  • 不要使用任何模糊半径大于 0 的阴影
  • 不要使用渐变，三种全部禁止
  • 不要使用 4–8px 的暧昧圆角
  • 不要在卡片内使用超过 2 级字号
  • 不要使用低饱和色，饱和度必须 ≥ 70%
  • 不要添加除位移以外的过渡缓动
05

验收标准

Acceptance
  • 所有可见边框粗细一致
  • 所有阴影方向一致（右下）
  • 主色只出现在按钮、徽章、强调标记
  • 375 / 768 / 1440 三档无横向滚动
