02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 底 #EEF1F8，卡片 #F6F8FD，文字 #2D3142，次级 #6B7392
  • 关键配方：0 8px 0 深色底边 + 0 16px 30px 柔和投影 + inset 0 2px 0 白色高光
  • 圆角：卡片 26px，按钮 999px，图标 14px
  • 主色 #8EA9FF，辅助 #7FD8BE、#FFB4A2
  • 字重：标题 800，正文 500
  • 字阶：15 / 17 / 22 / 34 / 64
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1180px，留白 24px
  • 卡片三列，间距 22px
  • 区块之间留白 70px，靠厚度而非线分隔
  • 移动端单列，标题 38px
03

组件与响应式行为

Components
  • 按钮：全圆角 + 7px 底边 + 外投影 + 内高光，按下时底边缩到 3px
  • 卡片：26px 圆角 + 8px 底边 + 内高光
  • 输入框：内凹（inset 阴影），圆角 16px
  • 图标：彩色圆角方块 + 内高光 + 4px 底边
04

禁止事项

Forbidden
  • 不要省略底边实心阴影，那是黏土感的来源
  • 不要使用 1px 细边框
  • 不要使用纯平面无厚度元素
  • 不要使用超过 3 种辅助色
  • 不要使用细字重（标题必须 800）
  • 不要给元素加纹理
05

验收标准

Acceptance
  • 所有可点元素都有实心底边
  • 卡片圆角 ≥ 22px
  • 标题字重 800
  • 375px 下无横向滚动
