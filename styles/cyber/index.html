02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景 #06060A，面板 #0C0C12
  • 霓虹主色 #00FFF0（青），副色 #FF2E97（品红）
  • 文字 #E8FFFE，次级 #7A9A97
  • 发光：text-shadow 0 0 12px 主色（透明度 .6）
  • 扫描线：repeating-linear-gradient 1px / 5px 间隔，透明度 ≤ .06
  • 字体：等宽字体为主，标题可用全大写加字距
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1200px，留白 24px
  • 区块用 1px 霓虹线分隔，不用背景色块
  • 信息密集，允许表格与终端式列表
  • 移动端扫描线透明度降到 .03，避免摩尔纹
03

组件与响应式行为

Components
  • 按钮：1px 霓虹边 + 透明底，hover 时整体发光
  • 卡片：深面板 + 1px 霓虹边，角落可加切角
  • 输入框：等宽字，光标用霓虹色，边框 1px
  • 导航：终端式前缀 > 或 $
04

禁止事项

Forbidden
  • 不要使用柔和阴影，只用发光
  • 不要使用圆角超过 4px
  • 不要让扫描线盖住正文（透明度必须极低）
  • 不要使用第三种霓虹色
  • 不要用衬线字体
  • 不要使用明亮背景
05

验收标准

Acceptance
  • 扫描线不引起摩尔纹，移动端尤甚
  • 霓虹色不超过 2 种
  • 正文对比度 ≥ 7:1（黑底白字）
  • 发光不影响文字边缘清晰度
