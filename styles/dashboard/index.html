02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 底 #0F1115，面板 #15181F，边线 #22272F
  • 文字 #E6E9EF，次级 #8B95A8，弱化 #6B7484
  • 强调 #3D7DFF，只用于数据高亮
  • 圆角：面板 6px，标签 3px，几乎直角
  • 数字用等宽字体，字号明显大于标签
  • 间距基数 4px，密度优先于留白
02

布局与响应式

Layout & Responsive
  • 左右分栏：侧栏 220px + 主区自适应
  • 主区用 12 列网格，卡片可占 3/4/6/12 列
  • 顶部固定工具栏 56px，包含筛选与时间范围
  • 移动端侧栏折叠为抽屉，主区单列
03

组件与响应式行为

Components
  • 按钮：1px 边框 + 深底，不填充
  • 卡片：深面板 + 1px 边线，内边距 16px
  • 表格：行高 36px，斑马纹用 rgba(255,255,255,.02)
  • 图表：只用折线与柱状，线宽 1.5px
04

禁止事项

Forbidden
  • 不要使用大圆角
  • 不要使用明亮背景
  • 不要使用超过一种强调色
  • 不要在数据区留大块空白
  • 不要使用装饰性插画
  • 不要让标签字号大于数字字号
05

验收标准

Acceptance
  • 一屏内可见至少 4 个数据模块
  • 数字均为等宽字体
  • 强调色只出现在数据高亮
  • 表格行高一致
