02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 底 #FCFAF3，文字 #222222，线条 #2A2A2A
  • 边框：2px 实线，圆角用不等值（如 18px 22px 16px 24px）制造手绘感
  • 分隔线用 2px 虚线
  • 不用阴影，靠线宽与歪斜表达层次
  • 字体：宋体或手写体，字距 0.04–0.1em
  • 字阶：15 / 17 / 22 / 34 / 64
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1140px，留白 50px
  • 卡片允许 ±1.5deg 的随机旋转
  • 区块间距 72px
  • 移动端取消旋转，留白 24px
03

组件与响应式行为

Components
  • 按钮：2px 手绘边框 + 不等值圆角，白底
  • 卡片：2px 边框 + 不等值圆角，可有 ±1deg 旋转
  • 输入框：2px 边框，focus 时加粗到 3px
  • 分隔：2px 虚线，不用实线
04

禁止事项

Forbidden
  • 不要使用完美等值圆角
  • 不要使用阴影
  • 不要使用直线实线做分隔
  • 不要让所有卡片旋转角度一致（会显得刻意）
  • 不要使用无衬线黑体作标题
  • 不要使用高饱和色块
05

验收标准

Acceptance
  • 存在至少两个不同圆角值的元素
  • 分隔线全为虚线
  • 没有任何 box-shadow
  • 移动端旋转归零，无横向滚动
