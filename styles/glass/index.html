02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景：深色底 + 至少两个大色斑（径向渐变），否则模糊无意义
  • 玻璃层：rgba(255,255,255,.14) + 1px rgba(255,255,255,.3) 边
  • 模糊：backdrop-filter blur 12–24px，上限 24px
  • 圆角：玻璃面板 18–24px，按钮 999px
  • 内阴影 inset 0 1px 0 rgba(255,255,255,.45) 制造边缘高光
  • 文字必须纯白或 90% 白，禁止灰色文字
02

布局与响应式

Layout & Responsive
  • 单列居中，最大宽 1100px，留白 24px
  • Hero 居中，玻璃卡片叠在色斑上
  • 最多 2 层玻璃垂直叠加，第三层开始互相干扰
  • 移动端：玻璃层减少到 1 层，blur 降到 10px
03

组件与响应式行为

Components
  • 按钮：主按钮白色实心胶囊，次按钮玻璃材质胶囊
  • 卡片：玻璃材质，圆角 20px，内阴影高光
  • 输入框：玻璃底 + 白色边，placeholder 用 rgba(255,255,255,.6)
  • 导航：玻璃条，底部 1px 白色半透明线
04

禁止事项

Forbidden
  • 背景不能是纯色，必须有可见色块
  • 同一屏内玻璃层不超过 2 层
  • blur 半径不超过 24px
  • 不要用纯白文字配纯白边框，必须有明度差
  • 不要给玻璃加投影以外的任何装饰
  • 不要用玻璃做表格和数据密集区域
05

验收标准

Acceptance
  • 关闭背景色斑后玻璃区域看起来是脏的（说明色斑是必要的）
  • 文字与背景对比度 ≥ 4.5:1
  • 玻璃层数 ≤ 2
  • 低端设备滚动无掉帧（blur 不超过 24px）
