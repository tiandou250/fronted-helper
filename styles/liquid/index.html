02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 底：深色 + 三处彩色光斑，blur 46px
  • 玻璃层：rgba(255,255,255,.09) + 1px rgba(255,255,255,.2) 边
  • 关键：inset 0 1px 0 rgba(255,255,255,.55) 顶部高光 + inset 0 -1px 0 底部弱光
  • backdrop-filter: blur(20px) saturate(160%)，saturate 不可省
  • 圆角：导航与按钮 999px，卡片 26px
  • 字阶：14 / 16 / 20 / 28 / 44
02

布局与响应式

Layout & Responsive
  • 单列居中，最大宽 1160px，留白 24px
  • 导航做成悬浮胶囊，不贴边（上下左右留 16–20px）
  • Hero 居中，卡片三列
  • 移动端导航退化为普通条，blur 降到 14px
03

组件与响应式行为

Components
  • 按钮：玻璃胶囊，顶部高光必须可见
  • 卡片：玻璃块，顶部高光 + 底部弱光
  • 输入框：玻璃底，focus 时边框变白 .4
  • 导航：独立悬浮胶囊，内外都有阴影
04

禁止事项

Forbidden
  • 不要省略 saturate(160%)，否则玻璃发灰
  • 不要使用纯色背景
  • 不要使用超过 2 层玻璃叠加
  • 不要让高光宽度超过元素宽度的 100%
  • 不要使用灰色文字
  • 不要把玻璃用在表格上
05

验收标准

Acceptance
  • 玻璃元素顶部有明显高光线
  • 背景色斑可见且柔化
  • 文字对比度 ≥ 4.5:1
  • 滚动流畅无明显掉帧
