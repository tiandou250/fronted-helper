02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 底 #FEF7FF，卡片 #F7F2FA，主色 #6750A4，文字 #1D1B20
  • 次级文字 #49454F，容器色 #E8DEF8
  • 圆角：卡片 20px，按钮 999px，输入框 4px
  • 阴影：极轻（0 1px 3px），主要靠表面明度分层
  • 字阶：14 / 16 / 22 / 28 / 57（M3 标准字阶的裁剪版）
  • 标题字重 400，按钮与标签字重 500
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1200px，留白 24px
  • 区块顺序：顶栏 → Hero → 卡片组 → FAB 位置
  • 卡片间距 20px，圆角 20px
  • 移动端单列，FAB 固定在右下 16px
03

组件与响应式行为

Components
  • 按钮：全圆角填充，字重 500，主色底
  • 卡片：容器色底 + 20px 圆角，无边框
  • 输入框：4px 圆角，1px 描边，focus 时 2px
  • 图标：填充式 Material Symbols，圆形色底
04

禁止事项

Forbidden
  • 不要使用重阴影，M3 靠明度分层
  • 不要使用 8px 以下的圆角（按钮必须全圆角）
  • 不要使用纯黑文字 #000
  • 不要使用超过一种主色
  • 不要用描边图标混搭填充图标
  • 不要在卡片间使用分隔线
05

验收标准

Acceptance
  • 卡片无边框、无重阴影
  • 按钮为全圆角
  • 文字使用 #1D1B20 而非纯黑
  • 触控目标 ≥ 48×48px
