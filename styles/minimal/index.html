02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景 #FFFFFF，卡片 #FAFAFA
  • 文字 #1A1A1A，次级 #8A8A8A，分隔线 #EDEDED
  • 圆角：卡片 0，按钮 2px
  • 阴影：全站不使用阴影
  • 字阶：14 / 16 / 20 / 28 / 44，标题字距 -0.02em
  • 间距基数 8px，区块间距 120px
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1040px，左右留白 24px
  • 区块顺序：导航 → Hero → 说明段 → 特性列表 → 页脚
  • 正文栏宽不超过 720px，其余全部留白
  • 移动端区块间距降到 72px，留白 20px
03

组件与响应式行为

Components
  • 按钮：纯文字 + 底部 1px 实线，无背景无边框
  • 卡片：无边框无阴影，只用 1px #EDEDED 分隔
  • 输入框：只有底部 1px 边线，focus 时线变 #1A1A1A
  • 导航：小字，字距 0.1em，无下划线，当前项加粗
04

禁止事项

Forbidden
  • 不要使用任何 box-shadow
  • 不要给卡片加背景色块或边框
  • 不要使用超过两种字体
  • 不要使用超过 3 级灰阶
  • 不要使用彩色强调
  • 不要让任何文本容器宽于 720px
05

验收标准

Acceptance
  • 全站 box-shadow 数量为 0
  • 灰阶不超过 3 种
  • 所有文字对比度 ≥ 7:1
  • 375px 下无横向滚动
