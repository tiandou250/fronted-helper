02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景 #FFFFFF，文字 #111111，次级 #767676
  • 唯一强调色 #E4002B，只用于当前状态与标记
  • 圆角 0，阴影 0
  • 结构线：#111 1px 与 2px 两级，内部线 #DCDCDC
  • 字阶：10 / 15 / 22 / 34 / 72，标题行高 0.96，字距 -0.015em
  • 间距基数 8px，区块间距 88px
02

布局与响应式

Layout & Responsive
  • 12 列网格，最大宽 1440px，左右留白 48px
  • Hero 左对齐，标题占 1–8 列，说明文字占 9–12 列
  • 所有元素左对齐到网格，不做居中排版
  • 移动端退回单列，留白 20px，标题降到 40px
03

组件与响应式行为

Components
  • 按钮：矩形直角，1px 实线边框，无填充
  • 卡片：无边框，靠 1px 细线与网格间隙分区
  • 输入框：只有底部 1px 边线
  • 标签：等宽字体，大写，字距 0.18em，10–12px
04

禁止事项

Forbidden
  • 不要使用圆角
  • 不要使用阴影
  • 不要居中排版任何区块
  • 不要使用第二种强调色
  • 不要用图标，用数字与细线代替
  • 不要给文字加渐变或描边
05

验收标准

Acceptance
  • 所有块级元素左边缘对齐到 12 列网格
  • 强调色出现次数不超过 6 处
  • 全站圆角为 0
  • 最小字号不低于 10px，正文不低于 15px
