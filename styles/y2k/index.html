02 结构化 Prompt
01

视觉 Token

Visual Tokens
  • 背景：银灰渐变 #D8DEF0 → #B9C2DC → #EEF2FB，必须带金属过渡
  • 主色 #2B5BFF，文字 #1B2559
  • 高光：顶部白色渐变遮罩，透明度 0.7 向下衰减
  • 圆角：胶囊 999px，卡片 18px
  • 按钮必须有底部实心阴影（0 4px 0 深色）模拟厚度
  • 字阶：14 / 16 / 20 / 28 / 40，标题字重 800
02

布局与响应式

Layout & Responsive
  • 单列，最大宽 1180px，留白 24px
  • Hero 左对齐，标题最多两行
  • 卡片三列，间距 20px
  • 移动端单列，标题降到 40px
03

组件与响应式行为

Components
  • 按钮：亮蓝实心 + 底部 4px 深蓝硬阴影，按下时阴影收缩
  • 卡片：半透明白 + 内阴影高光，圆角 18px
  • 输入框：白底，边线 1px rgba(27,37,89,.15)
  • 图标：圆形渐变底，带白色高光
04

禁止事项

Forbidden
  • 不要使用纯白背景，必须有金属渐变
  • 不要使用扁平按钮，必须有厚度感
  • 不要使用深色背景
  • 不要超过两种蓝色
  • 不要使用无衬线细体作标题
  • 不要去掉顶部高光
05

验收标准

Acceptance
  • 首屏能看到金属渐变过渡
  • 按钮有明确的底部阴影厚度
  • 标题字重不低于 800
  • 375px 下无横向滚动
